ACTIVATION DU TABLEAU DE BORD

Connecter ROCOCO à Supabase

Cette configuration se fait une seule fois. Elle active la connexion sécurisée, les photos et les tarifs modifiables.

01

Créer le projet

Ouvrez Supabase et créez un nouveau projet gratuit pour ROCOCO.

Ouvrir Supabase ↗
02

Préparer la base de données

Dans Supabase, ouvrez SQL Editor. Copiez tout le contenu du fichier supabase-setup.sql, collez-le dans l’éditeur, puis cliquez sur Run.

Télécharger le fichier SQL ↓
03

Créer le compte propriétaire

Ouvrez Authentication → Users → Add user. Utilisez onglesrococo@gmail.com et choisissez un nouveau mot de passe privé.

N’utilisez pas un mot de passe déjà partagé dans un message ou placé dans le code du site.

04

Copier les informations publiques

Ouvrez Project Settings → Data API, puis copiez le Project URL et la Publishable key, parfois appelée clé anon.

05

Connecter le site

Ouvrez supabase-config.js et remplacez les deux valeurs commençant par PASTE_. N’utilisez jamais la clé service_role.

06

Publier et se connecter

Envoyez les fichiers mis à jour vers GitHub, puis ouvrez le tableau de bord ROCOCO.

Accéder au tableau de bord →
Protection incluse

Les visiteurs peuvent voir le contenu publié, mais seul le compte ROCOCO authentifié peut ajouter, modifier ou supprimer les photos et les tarifs.
